## 使用提供商 { #working-with-providers }

Koog 允许您在两个层面上使用 LLM 提供商：

* 使用 **LLM 客户端** 直接与特定提供商交互。
  每个客户端都实现了 `LLMClient` 接口，负责处理该提供商的认证、
  请求格式化和响应解析。
  详情请参阅 [LLM 客户端](prompts/llm-clients.md)。

* 使用 **提示词执行器** 作为更高级别的抽象，它包装一个或多个 LLM 客户端，
  管理其生命周期，并在不同提供商之间提供统一的接口。
  它可以在提供商之间切换，
  并可选择性地回退到配置的提供商和 LLM（使用相应的客户端）。
  您可以创建自己的执行器，或使用针对特定提供商的预定义提示词执行器。
  详情请参阅 [提示词执行器](prompts/prompt-executors.md)。

使用提示词执行器提供了一个位于一个或多个 LLMClient 之上的更高级别层。
它管理客户端的生命周期，并暴露跨提供商的统一接口。
在多提供商设置中，它可以在提供商之间路由请求，并可根据需要为核心请求回退到指定的客户端。
您可以创建自己的执行器，或使用预定义的执行器——单提供商和多提供商选项均可用。
